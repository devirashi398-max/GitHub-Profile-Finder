# GitHub Profile Finder

I built this project to practice JavaScript and learn how to work with APIs.

It lets you search for a GitHub user and view their profile details, including their profile picture, name, bio, followers, and public repositories.

## Built With

- HTML
- CSS
- JavaScript
- GitHub REST API

## How It Works

Enter a GitHub username and click the Search button. The app fetches the user's public profile data from the GitHub API and displays it on a separate page.

You can also click the username to open their GitHub profile.

## What I Learned

While building this project, I learned how to:

- Fetch data from an API using `fetch()`
- Work with `async/await` and JSON
- Display API data dynamically using JavaScript
- Handle invalid usernames
- Pass data between pages using URL parameters

## Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Search for any GitHub username.
